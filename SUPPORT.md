# Stöd Pärmetikett Generator

Pärmetikett Generator är en **gratis, reklamfri** Windows-app. Källkoden
finns publik på GitHub: <https://github.com/Tokke2/P-rm>.

Du behöver **inte** donera, skapa något konto eller teckna någon
prenumeration för att använda appen. Donationer är ett **frivilligt** sätt
att stötta utveckling och underhåll — de låser inte upp några extra
funktioner.

## Donera

| Tjänst | Länk |
| --- | --- |
| PayPal | [Donera via PayPal](https://paypal.me/Rickard3dPrint) |
| Ko-fi | [Bjud på en kaffe via Ko-fi](https://ko-fi.com/tokke2) |

Du hittar samma länkar i appen:

1. Högerklicka på Pärmetikett Generators fönster och välj
   **💖 Stöd Pärmetikett Generator…** (eller menyn **Hjälp & Stöd**).
2. Välj **Donera via PayPal** eller **Bjud på en kaffe**.
3. Länken öppnas i din standardwebbläsare. Kontrollera mottagare och
   belopp hos betaltjänsten innan du bekräftar.

Om webbläsaren inte öppnas från appen kan du använda länkarna i tabellen
direkt.

### Betalning och integritet

Pärmetikett Generator öppnar bara länken; betalningen sker hos PayPal
eller Ko-fi. Appen hanterar inte dina kort- eller betalningsuppgifter.
Eventuella krav på konto, tillgängliga betalningssätt och villkor beror
på den tjänst du väljer.

## Hjälp till utan att donera

* **Dela projektet** med någon som kan ha nytta av det eller ge
  [Pärmetikett Generator en stjärna på GitHub](https://github.com/Tokke2/P-rm).
* **Rapportera fel eller föreslå förbättringar**
  ([Issues](https://github.com/Tokke2/P-rm/issues)). Beskriv vad du
  försökte göra, vad som hände och vad du förväntade dig. Vid fel: ange
  gärna Windows-version och hur du startade appen (folder.py /
  pythonw / autostart). Ta bort etiketttexter med personuppgifter innan
  du delar loggar eller skärmbilder.
* **Bidra med kod, tester eller dokumentation.** Börja med README för
  installation och `AGENTS.md` för arbetsreglerna; testerna ligger i
  `tests/` och körs med `python -m unittest discover -s tests`.

## Behöver du hjälp med appen?

* **Komma igång:** se installationsavsnittet i README och Hjälp-fliken i
  appen.
* **Uppdatera appen:** knappen **⬇️ Sök uppdatering (REQ-K4)** eller
  menyn **Uppdatera**; auto-uppdatering 00:00 varje dag kan slås på/av i
  menyn. Installationer som inte kan starta: `python Script/updater.py`.
* **Felen syns i appen:** fliken **Loggar** visar alla aktiva fel; ett
  fel försvinner automatiskt när det åtgärdats.
* **Hittar du inte svaret?** Gå till
  [projektsidan](https://github.com/Tokke2/P-rm) för tidigare felrapporter
  eller lämna ett förslag.
